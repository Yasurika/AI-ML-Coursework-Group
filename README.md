# AI and Machine Learning Coursework

## Project Overview

This project focuses on implementing, training, evaluating, and comparing machine learning and deep learning models using the CIFAR-10 image classification dataset.

The project explores different neural network architectures and techniques to understand their performance, learning behaviour, and generalisation capabilities.

## Coursework Exercises

### Exercise 1 – Multi-Layer Perceptron (MLP)
Implementation and evaluation of a Multi-Layer Perceptron model for image classification.

### Exercise 2 – Convolutional Neural Network (CNN)
Implementation and evaluation of a CNN model, including a comparison with the MLP model.

### Exercise 3 – Regularisation Techniques
Investigation of regularisation techniques, including Dropout and Data Augmentation, to improve model generalisation.

### Exercise 4 – Model Architecture Comparison
Investigation of different CNN architectures by varying network width and depth.

## Dataset

**CIFAR-10** – A dataset containing 60,000 colour images across 10 different classes, used for image classification experiments.

## Project Objectives

- Implement different neural network architectures.
- Train and evaluate models using consistent experimental settings.
- Compare model performance and complexity.
- Investigate regularisation techniques.
- Analyse the effects of model width and depth.
- Document experimental results and findings.
